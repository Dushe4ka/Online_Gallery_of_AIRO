### 📌 Online Gallery of AIRO – Telegram-бот для художественной галереи  

![Online Gallery of Aigo](media/1.jpg)  

## 📖 Описание проекта  
**Online Gallery of AIRO** – это Telegram-бот, позволяющий пользователям просматривать каталог картин, узнавать о художнике и его стиле, получать анонсы мероприятий и видеоконтент. Администраторы могут загружать новые изображения и видео с описанием, а бот автоматически рассылает обновления всем подписчикам.  

## 🎯 Основные возможности  

### 🔹 Функционал для пользователей  
✅ **Команда /start** – приветственное сообщение и регистрация.  
✅ **Главное меню** с разделами:  
   - 🖌 **О художнике** – информация о мастере.  
   - 🎨 **О направлении** – художественный стиль.  
   - 🖼 **Каталог картин** – просмотр изображений с описанием.  
   - 📅 **Мероприятия** – анонсы выставок, событий.  
   - 👥 **Наши гости** – фото и видео с выставок.  
   - 🤝 **Сотрудничество** – информация для партнёров.  
   - 📞 **Контакты** – связь с организаторами.  

### 🔹 Функционал для администраторов  
✅ **Команда /admin** – вход в админ-панель (только для списка админов).  
✅ **Клавиатура администратора** с кнопками:  
   - ➕ **Добавить фото**  
   - ➕ **Добавить видео**  
   - ➕ **Добавить описание**  
✅ **Автоматическая рассылка** обновлений пользователям после загрузки нового контента.  

## ⚙ Техническая реализация  

- **Язык разработки:** Python  
- **Фреймворк:** aiogram  
- **База данных:** SQLite  
- **Структура проекта:**  
```
/art_bot
│── bot.py          # Основной файл бота
│── admin.py        # Админ-панель
│── database.py     # Работа с SQLite
│── config.py       # Конфигурация (токен, ID админов)
│── requirements.txt # Список зависимостей
```

## 🗄 Структура базы данных  

### 🔹 Таблица `users` (Пользователи)  
| Поле   | Тип данных | Описание                  |  
|--------|-----------|---------------------------|  
| user_id | INTEGER  | Telegram ID пользователя  |  

### 🔹 Таблица `content` (Контент)  
| Поле       | Тип данных | Описание                      |  
|------------|-----------|--------------------------------|  
| id         | INTEGER   | Уникальный ID                 |  
| section    | TEXT      | Раздел (catalog, events и т. д.) |  
| media_type | TEXT      | Тип контента (photo, video)   |  
| media_url  | TEXT      | file_id Telegram              |  
| description | TEXT     | Описание контента             |
